# Flask APP

A repository created for Telegram bots. The current tokens will not work; however, you can modify and adapt the code for your own use. If you wish to test the code, remove the existing tokens and replace them with your own. Then, run:
```bash
uv sync
```
to install all necessary dependencies. Next, execute:
```bash
uv run app.py
```
and check `https://localhost:5000` in your browser. To make the bots functional, deploy the application to a server and specify the appropriate bot endpoint.
